## Evidence limits

- `apps/story-generator/test-data/test-story.yaml` has narrative, choice and roll labels but no branches on its choice/roll scenes; it is a format sample, not a playback parity fixture. The larger `Test-Story-6-9.yaml` has authored roll branches and video special endings. The 3D stage fixture is `glowdome-3d-stage-story.yaml`. All are repository test content, not captured user sessions.
- `Models/Scenario.cs` declares `Scene.Type` as a string. Its mapper accepts numeric **strings**; source tests do not prove that a raw numeric JSON token deserializes into that property. A sanitized response captured through the actual API/Blazor deserializer is required to freeze this edge.
- This audit found no existing `<mystira-player>` implementation in the Player source. The current app is a standalone React root. The documented custom element and Blazor wrapper are future Spec 5 work.
